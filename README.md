# 3D Child Room Textures - WebGL & Three.js

## Overview
This project demonstrates the use of texture mapping, lighting, and 3D transformations using the **Three.js** library. It was created as a part of the Computer Graphics coursework.

## Features
* **3D Geometry:** Utilizes `THREE.BoxGeometry` to simulate room walls.
* **Texture Mapping:** Applies four distinct, child-friendly textures (animals, space, etc.) to the faces of the cube.
* **Lighting:** Implements `AmbientLight` and `DirectionalLight` for realistic material illumination.
* **Interactivity:** Features clockwise auto-rotation and allows user manipulation via `OrbitControls`.

## Technologies Used
* HTML5 / CSS3
* JavaScript
* Three.js (WebGL)
